Il metodo

Il ciclo di una release

1

Scelgo la release e la pubblico

2

Push su GitHub, Netlify ricostruisce il sito

3

Suite di riferimento sul sito pubblico

4

Run della pipeline, 15–26 minuti

5

Punteggio dei verdetti contro il catalogo

6

Analisi dei fallimenti, test per test

7

Rispondo alle schede di revisione

↻

Nuova run, o release successiva

La memoria non si svuota fra le release: ogni run eredita suite, verdetti e risposte delle precedenti.

Questo è il giro che ripeto per ogni release. Le run su una stessa release servono a vedere se la pipeline converge dopo le risposte umane; il passaggio alla release successiva cambia la verità sotto i piedi della pipeline. Una run costa fra 0,11 e 0,25 dollari di chiamate ai modelli.
